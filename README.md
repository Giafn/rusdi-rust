# rudis-lite

`rudis-lite` is a small Rust CLI that installs Rudis slash commands for **Claude Code**.
It intentionally does less than the full [`rudis`](../rudis) Python CLI: there is no
TUI, web app, marketplace, profile catalog, utility catalog, GitLab access, or support
for other AI agents.

## Install

### From a release binary

Download the binary for your platform, put `rudis-lite` on `PATH`, and verify it:

```bash
rudis-lite version
```

### From source

Install Rust stable, then run:

```bash
git clone <repository-url>
cd rudis-lite
cargo install --path .
```

The installed binary is `rudis-lite`.

## Use with Claude Code

From the root of a project where Claude Code runs:

```bash
rudis-lite init
```

This creates `.claude/commands/` and installs the bundled commands. Start or reload
Claude Code, then use commands such as:

```text
/rudis.specify
/rudis.plan
/rudis.tasks
/rudis.implement
/rudis.test
```

Install into another project with `rudis-lite init /path/to/project` or explicitly use
the current directory with `rudis-lite init --here`.

## Commands

```text
rudis-lite list
rudis-lite init [--here] [PROJECT_DIR]
rudis-lite update [--here] [PROJECT_DIR] [--dry-run]
rudis-lite version
```

`list` prints the bundled slash commands. `update` refreshes only files previously
generated by `rudis-lite`; `--dry-run` reports changes without writing. Files without
the Rudis Lite ownership marker are never overwritten or deleted.

## Uninstall

Uninstalling the binary does not remove project commands. Review and remove only the
files carrying the Rudis Lite marker if you want to remove them from a project.

## Updating from upstream Rudis

The full Rudis repository remains the reference at `../rudis`. When it changes, compare
`../rudis/templates/commands/` with this project's `templates/commands/`, port only
Claude Code command changes, update the pinned revision in `src/templates.rs`, and run:

```bash
cargo fmt --check
cargo clippy --all-targets --all-features -- -D warnings
cargo test
```

Do not copy the Python CLI, TUI, web application, marketplace, profiles, utilities,
governance runtime, or other-agent integrations.
