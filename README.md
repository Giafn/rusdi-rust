# rudis-lite

`rudis-lite` is a small Rust CLI that installs Rudis slash commands for **Claude Code**.
It intentionally does less than the full [`rudis`](../rudis) Python CLI: there is no
TUI, web app, marketplace, profile catalog, utility catalog, GitLab access, or support
for other AI agents.

## Install

### From a release binary

Download the binary for your platform from [GitHub Releases](https://github.com/Giafn/rusdi-rust/releases), put `rudis-lite` on `PATH`, and verify it:

```bash
rudis-lite version
```

### Linux installer

The installer supports Linux x86_64 and ARM64. It verifies `SHA256SUMS` before
installing to `${XDG_BIN_HOME:-$HOME/.local/bin}`:

```bash
curl --proto '=https' --tlsv1.2 -sSf https://raw.githubusercontent.com/Giafn/rusdi-rust/main/install.sh | sh
```

The installer does not require administrator privileges. Add the chosen bin directory
to `PATH` if it is not already present.

### Windows PowerShell installer

Run PowerShell as a normal user:

```powershell
irm https://raw.githubusercontent.com/Giafn/rusdi-rust/main/install.ps1 | iex
```

The Windows installer supports x86_64, verifies `SHA256SUMS`, and installs into
`$HOME\bin\rudis-lite.exe` by default. Set `$env:RUDIS_LITE_BIN` to choose another
user-writable directory, then add that directory to `PATH`.

### From source

Install Rust stable, then run:

```bash
git clone <repository-url>
cd rudis-lite
cargo install --path .
```

The installed binary is `rudis-lite`.

## Use with Claude Code

From the root of a project where Claude Code runs:

```bash
rudis-lite init
```

This creates `.claude/commands/` and installs the bundled commands. Start or reload
Claude Code, then use commands such as:

```text
/rudis.specify
/rudis.plan
/rudis.tasks
/rudis.implement
/rudis.test
```

Install into another project with `rudis-lite init /path/to/project` or explicitly use
the current directory with `rudis-lite init --here`.

## Commands

```text
rudis-lite list
rudis-lite init [--here] [PROJECT_DIR]
rudis-lite update [--here] [PROJECT_DIR] [--dry-run]
rudis-lite self-update
rudis-lite version
```

`list` prints the bundled slash commands. `update` refreshes only files previously
generated by `rudis-lite`; `--dry-run` reports changes without writing. Files without
the Rudis Lite ownership marker are never overwritten or deleted.

`self-update` is separate: it downloads the latest verified binary release for the
current supported platform. It does not change project command files. The current
release assets are Linux x86_64, Linux ARM64, and Windows x86_64.

## Uninstall

Uninstalling the binary does not remove project commands. Review and remove only the
files carrying the Rudis Lite marker if you want to remove them from a project.

## Updating from upstream Rudis

The full Rudis repository remains the reference at `../rudis`. When it changes, compare
`../rudis/templates/commands/` with this project's `templates/commands/`, port only
Claude Code command changes, update the pinned revision in `src/templates.rs`, and run:

```bash
cargo fmt --check
cargo clippy --all-targets --all-features -- -D warnings
cargo test
```

Do not copy the Python CLI, TUI, web application, marketplace, profiles, utilities,
governance runtime, or other-agent integrations.

## Publishing a release

Maintainers update `CHANGELOG.md`, commit the version change, then create and push a
tag such as:

```bash
git tag v0.2.0
git push origin v0.2.0
```

GitHub Actions builds the Linux x86_64, Linux ARM64, and Windows x86_64 binaries and
publishes them with `SHA256SUMS`. The workflow must finish before `install.sh`,
`install.ps1`, or `self-update` can use that release.
